# Soliman Alktaifan · Portfolio

Live: https://iiciel.github.io/Portfolio/

React 19 + Vite + Tailwind preflight, plain CSS in `src/index.css`. Content lives in `src/content.ts` and `src/projects.ts`; screenshots in `assets/img/` (WebP, full and `-sm` sizes).

```
npm install
npm run dev
npm run build && npm run preview
```

Pushing to `master` builds and deploys to GitHub Pages through `.github/workflows/deploy.yml`.
Design decisions: `DESIGN.md`.
